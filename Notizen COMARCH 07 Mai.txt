Erste Vorlesung

- Load instruction hat höchsten Delay
- allgemeiner Fall soll am schnellsten sein (Rechnen und Schreiben)
- Branch und Jump am schnellsten bei 1-Takt Prozessor
- Lösung dafür ist Pipelining

Pipelining
- Wäsche Waschen
- alles hintereinander 8 Stunden bei 4 Iterationen
- anderen Sachen warten alle

- die wartenden Sachen ausnutzen und direkt die neue Wäsche rein tun (Schrank, Waschmaschine, usw)
- speedup faktor von 2.3 insgesamt nur noch 4 Stunden
- Bedingungen für den Speedup ist dass alle sachen gleichlang dauern es geht nur wenn alle Komponenten Schrank etc gleich lang dauert

CPU wird in 5 unterschritte unterteilt:
- IF: instruction fetch
- ID: instruction deocde
- EX: execute Alu operation
- MEM: Access Memory Operand (Lesen oder Schreiben)
- WB: Berechnung vom Execute wird zurück geschrieben

Lesen und Schreiben wird in zwei Schritten verwendet oben. Daher wird Load instruction auf zwei Takte aufgeteilt einmal auf steigende und einmal auf fallende Flanke

Laden wird nicht besser bei Pipelining da zusätzliche Hardware benötigt wird.
Durschnittliche Zeit der Instructionen wird deutlich besser

Man kann laden order rechnen bei MIPS Architektur => extra so ausgelegt wegen Pipelining 
Daher auch Instruction Memory und Data Memory auch getrennt
